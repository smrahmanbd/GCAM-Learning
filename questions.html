How to make it stick: six memory techniques built into this page

1. Retrieve before you read

Answer from memory first, aloud or with Write my answer first. Struggling to recall is what strengthens memory; rereading feels productive but fades fast.

2. Space it out

Mark each question honestly. I knew it sends it away for longer (1, 3, 7, 14, then 30 days); Review again brings it back tomorrow. Choose Due for review to see only what is due today.

3. Understand the why

Every answer comes with an intuition: one line on why it must be so. A fact you can rebuild from a reason is a fact you cannot lose.

4. Picture it

Every answer also has a memory hook, a vivid and slightly absurd image. Strange pictures stick; dry sentences slide off. Use Hint to see the hook as a cue before the answer.

5. Place it

The memory palace view parks each module in a room of a place you know. Walk the route in your head and each room hands you its module.

6. Mix it up

Shuffle across modules and goes. Mixing topics forces you to decide which idea applies, which is exactly what an exam or a research problem asks of you.
