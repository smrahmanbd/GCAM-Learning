Glossary

Every new word in the three goes, in plain language, with the module where it first appears.

105 terms

Absolute-cost logit
A logit on cost differences (exp of cost), used for technologies within a mode. Go 3, module 3.2
Add-on file
A small XML input file that changes selected values and is loaded after the base files. Go 3, module 3.1
AgLU
GCAM's agriculture and land use module. Go 2, module 2.6
AR6 category
One of eight IPCC classes (C1 to C8) that sort pathways by the warming they lead to. Go 1, module 1.5
Base year
The calibrated starting year of the model; 2021 in recent GCAM versions. Go 1, module 1.6
BaseX database
The XML database GCAM writes its results to, read with queries. Go 3, module 3.1
Batch file
An XML file that defines several scenarios to run in one go. Go 3, module 3.5
Benchmarking
Comparing results with other models or databases to check plausibility. Go 3, module 3.6
Blind spot
Something a model does not represent and so cannot tell you about. Go 3, module 3.8
Broyden's method
A quasi-Newton root finder that updates an approximate Jacobian cheaply each step. Go 2, module 2.2
Calibration
Setting parameters so the model reproduces observed base-year data. Go 2, module 2.3
Capacity factor
Actual output divided by the output if the plant ran at full power all year. Go 2, module 2.4
Carbon budget
How much more CO2 can be emitted before a temperature limit is crossed, with a stated probability. Go 1, module 1.2
Carbon density
Carbon stored per area in vegetation and soil. Go 2, module 2.6
Carbon intensity
CO2 released per unit of energy (CO2 ÷ energy). Go 1, module 1.3
Carbon price
A charge per tonne of CO2 emitted, which raises the cost of each option in proportion to its emissions. Go 1, module 1.4
CMIP7
The next round of the climate-model intercomparison; its 2026 scenarios each come from a different IAM. Go 1, module 1.5
Community guidelines
JGCRI's guidance for describing GCAM and its modifications in papers. Go 3, module 3.8
Concentration
How much CO2 is in the air, in parts per million (ppm). About 280 before industry, about 420 today. Go 1, module 1.2
Consistency
Every part of the model agrees: energy used equals energy made, and emissions match the fuels burned. Go 1, module 1.1
Consumption
The part of a withdrawal that is not returned to the source. Go 2, module 2.7
Convergence downscaling
Downscaling in which country intensities move towards the regional average over time. Go 3, module 3.7
Cost-benefit model
A small IAM that weighs the cost of cutting emissions against the damage of warming, for example DICE. Go 1, module 1.1
Coverage
Share of all outcomes of interest that a scenario-discovery box captures. Go 3, module 3.6
Credit market
A policy market where some technologies produce credits and others must use them. Go 3, module 3.5
Cumulative emissions
The running total of CO2 emitted over time. Go 1, module 1.2
Degree-days
A measure of how much heating or cooling a climate needs. Go 2, module 2.5
Density
Share of runs inside a scenario-discovery box that are outcomes of interest. Go 3, module 3.6
Discount rate
The yearly rate used to convert future money into today's value; a higher rate makes the future count less. Go 1, module 1.4
Downscaling
Turning results for a model region into results for the countries inside it. Go 3, module 3.3
Emission factor
Tonnes of CO2 released per unit of output, for example 0.9 t CO2 per MWh from a coal plant. Go 1, module 1.4
Emissions constraint
A policy that fixes emissions; the model finds the carbon price that meets it. Go 1, module 1.6
Endogenous
Calculated by the model itself, such as energy prices. Go 2, module 2.1
Energy intensity
Energy used per dollar of economic output (energy ÷ GDP). Go 1, module 1.3
Energy service
What people actually want from energy: light, warmth, travel, cooling, materials. Go 1, module 1.3
Environmental flow requirement
Water left in rivers to protect ecosystems. Go 2, module 2.7
Equilibrium
The price at which the quantity buyers want equals the quantity sellers offer. Go 1, module 1.4
Excess demand
Demand minus supply at a given price; zero at equilibrium. Go 2, module 2.2
Exogenous
Decided outside the model and fed in as an assumption, such as population. Go 2, module 2.1
Final energy
Energy delivered to users, such as electricity, petrol and heat. Go 1, module 1.3
GCAM
Global Change Analysis Model: an open-source, process-based IAM from PNNL/JGCRI linking economy, energy, land, water and climate. Go 1, module 1.6
GCAM-KSA
A version of GCAM with Saudi Arabia as its own region, developed with KAPSARC. Go 3, module 3.3
gcamdata
The R package that builds GCAM's input XML files from source data. Go 3, module 3.1
Generalised cost
Money cost plus the money value of travel time. Go 2, module 2.5
Geographic land unit (GLU)
The overlap of a GCAM region and a river basin; GCAM's spatial unit for land. Go 2, module 2.6
Graded supply curve
A resource split into grades of rising extraction cost. Go 2, module 2.4
Grey literature
Reports and discussion papers not published in peer-reviewed journals, such as KAPSARC papers. Go 3, module 3.3
Harmonisation
Rescaling country results so they add up to the regional total. Go 3, module 3.7
Hector
The simple climate model inside GCAM that turns emissions into concentrations, forcing and temperature. Go 1, module 1.6
Hindcast
Running a model over a past period to compare with what actually happened. Go 3, module 3.4
IAMC format
The common data template of the Integrated Assessment Modeling Consortium: model, scenario, region, variable, unit, years. Go 3, module 3.8
Income elasticity
The % change in demand for a 1% change in income per person. Go 2, module 2.1
Input (assumption)
A value the modeller chooses, such as population, technology costs or a policy. Go 1, module 1.1
input-cost
The non-fuel cost element of a transport technology in GCAM's input files. Go 3, module 3.5
Integrated assessment model (IAM)
A computer model that joins the economy, energy, land, water, emissions and climate into one consistent calculation to inform decisions. Go 1, module 1.1
Interpolation rule
Tells GCAM how to fill share-weights or values between and after the years you set. Go 3, module 3.5
Jacobian
The table of how each market's excess demand changes when each price changes. Go 2, module 2.2
Kaya identity
CO2 = population × GDP per person × energy per GDP × CO2 per energy; always true because the units cancel. Go 1, module 1.3
KLEAM
GCAM's v9.0 macro module: capital, labour, energy, agriculture and materials. Go 2, module 2.1
Labour productivity
Output per worker; its growth rate is a key GDP assumption. Go 2, module 2.1
Land-use change emissions
CO₂ released or absorbed when land cover changes. Go 2, module 2.6
LEAP
Low Emissions Analysis Platform, a widely used national energy planning tool. Go 3, module 3.7
Levelised cost (LCOE)
All lifetime costs of a plant divided by its lifetime output, in $/MWh. Go 2, module 2.4
Lever
A single assumption you change to test its effect. Go 3, module 3.4
LMDI
Logarithmic mean Divisia index: an exact decomposition of a change into contributing factors. Go 3, module 3.6
Load factor
People (or tonnes) carried per vehicle; divides the vehicle's cost and energy per km. Go 3, module 3.2
Logit
A formula that turns costs (or profits) into market shares. Go 2, module 2.3
Logit exponent
The parameter that sets how strongly shares respond to cost differences. Go 2, module 2.3
MAC curve
Marginal abatement cost curve: how much of a gas is cut at each price. Go 2, module 2.8
Market share
The fraction of a market supplied by one option, for example solar's share of new electricity. Go 1, module 1.4
Model intercomparison
Running several models on the same scenarios to compare results and understand why they differ. Go 3, module 3.3
Nest
One level of a choice tree, with its own logit. Go 2, module 2.3
Net zero
Emissions released equal emissions removed, so the total in the air stops rising. Go 1, module 1.2
Partial equilibrium
Detailed markets for some sectors, with the rest of the economy taken as given. Go 2, module 2.2
Present value
What a future amount is worth today: future amount ÷ (1 + r)^years. Go 1, module 1.4
Price elasticity
The % change in demand for a 1% change in its price. Go 2, module 2.5
Primary energy
Energy as nature provides it: coal, oil, gas, uranium, sunlight, wind, biomass. Go 1, module 1.3
Process-based model
A detailed IAM that represents technologies, sectors and regions and chooses among them by cost, for example GCAM. Go 1, module 1.1
Profit rate
Revenue minus costs per unit of land. Go 2, module 2.6
Projection
What follows from a set of assumptions. Unlike a prediction, it does not claim to say what will happen. Go 1, module 1.1
Radiative forcing
Extra heat trapped by greenhouse gases, in watts per square metre (W/m²). Go 1, module 1.2
RCP
Representative Concentration Pathway: an earlier scenario set named by its forcing in 2100; the forcing numbers live on in SSP labels. Go 1, module 1.5
Recursive dynamics
Solving one period at a time using only current information. Go 2, module 2.2
Recursive-dynamic
Solving one period at a time without foresight, as GCAM does. Go 1, module 1.6
Reference scenario
A run with no new climate policy, used as the yardstick for policy runs. Go 1, module 1.6
Reproducible package
An archive with everything needed to rebuild a study's results. Go 3, module 3.8
Scenario
A consistent what-if story about the future with numbers attached; not a forecast. Go 1, module 1.5
Scenario matrix
A grid with SSP stories in rows and forcing levels in columns. Go 1, module 1.5
ScenarioComponents
The list of input files in a configuration, read in order. Go 3, module 3.5
Service demand
Total passenger-km or tonne-km demanded, driven by income and price elasticities. Go 3, module 3.2
Shadow price
In optimisation, the cost of tightening a constraint by one unit. Go 2, module 2.8
Share weight
A calibrated multiplier on each option's attractiveness, set to match base-year data. Go 2, module 2.3
Soft-link
Connecting two models by passing outputs as inputs between separate runs. Go 3, module 3.7
SSP
Shared Socioeconomic Pathway: one of five stories about how society develops, used as IAM inputs. Go 1, module 1.5
Superwell
The groundwater extraction cost model behind GCAM's groundwater grades. Go 2, module 2.7
Target finder
GCAM mode that searches for a price path meeting a climate target. Go 2, module 2.8
TCRE
Transient climate response to cumulative emissions: warming per 1,000 Gt of CO2, about 0.45 °C (likely 0.27–0.63). Go 1, module 1.2
Tornado chart
Bars showing how much the result moves when each input goes from low to high, one at a time. Go 3, module 3.6
UCD database
The University of California, Davis transport database behind GCAM's base transport data. Go 3, module 3.2
Value factor
The value of variable renewable output relative to average power; falls as their share grows. Go 2, module 2.4
Value of time
The money value travellers place on time spent travelling, tied to the wage. Go 2, module 2.5
Vehicle stock model
A model that tracks vehicles on the road from sales and survival curves. Go 3, module 3.7
Vintage
The cohort of plants built in one period, which keeps operating for its lifetime. Go 2, module 2.4
Withdrawal
Water taken from a river, lake, aquifer or the sea. Go 2, module 2.7
Xanthos
The global hydrology model that supplies GCAM's runoff. Go 2, module 2.7
